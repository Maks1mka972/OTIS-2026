# Лабораторная работа №1 — вариант 5

## Цель работы
Изучить математическое моделирование динамических систем, реализовать заданные модели в C++ с использованием ООП и исследовать их реакцию на различные входные воздействия.

## Вариант 5
- Model 1.5 — линейная модель с задержкой.
- Model 2.7 — релейная модель с гистерезисом.
- Model 3.9 — дифференциальное уравнение.

## Математические модели

### Model 1.5
`y[t+1] = a1*y[t] + a2*y[t-k] + b*u[t]`, где `k >= 1`.
Если индекс задержанного значения выходит за начало истории, начальное значение принимается равным нулю.

### Model 2.7
Используется реле с гистерезисом и порогом `epsilon`: при `u > epsilon` реле принимает `+1`, при `u < -epsilon` — `-1`; внутри полосы гистерезиса его состояние удерживается по текущему выходу. Затем вычисляется `y[t+1] = a*y[t] + b*relay`.
**Примечание:** если в методичке пороги или правило удержания состояния определены иначе, нужно привести функцию `calculateNext` в `src/Model27.cpp` точно к формуле преподавателя.

### Model 3.9
`dy/dt = b*tanh(u)`.
Метод Эйлера: `y[t+1] = y[t] + dt*b*tanh(u[t])`.

## Входные воздействия
- Постоянное: `u(t)=A`.
- Импульсное: `u(0)=A`, затем `u(t)=0`.
- Гармоническое: `u(t)=A*sin(t)`.

## Структура проекта
- `src/Model.h` — общий абстрактный интерфейс и структура точки.
- `src/Model15.h/.cpp` — Model 1.5.
- `src/Model27.h/.cpp` — Model 2.7.
- `src/Model39.h/.cpp` — Model 3.9.
- `src/main.cpp` — моделирование, вывод в консоль, запись CSV.
- `plot.py` — построение графиков из CSV.
- `docs/uml.puml` — исходник UML-диаграммы.
- `CMakeLists.txt`, `build.bat` — сборка.

## Сборка в Windows / Visual Studio
1. Открыл папку проекта в Visual Studio (Open a local folder).
2. Загрузил CMake.
3. Выбрал конфигурацию `Release` и собрал проект (Build > Build All).
4. Если CMake/компилятор настроен в PATH, можно запустить `build.bat`.
5. Запустил `task_01.exe`. Программа создаст девять CSV-файлов.

## Построение графиков
Установил Python, затем в терминале из папки проекта выполнил:
`py -m pip install -r requirements.txt`
После запуска программы выполнил:
`py plot.py`

## Параметры
В `src/main.cpp` заданы демонстрационные коэффициенты и шаги (`steps=40`, `dt=0.1`, `amplitude=1.0`).

## Вывод
В работе реализованы три модели варианта 5 на общем объектно-ориентированном интерфейсе. Для каждой модели выполняется расчёт при постоянном, импульсном и гармоническом воздействии. Результаты выводятся в консоль и сохраняются в CSV, по которым можно построить графики зависимости выхода от времени.
