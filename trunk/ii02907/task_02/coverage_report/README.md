# Отчёт gcovr

HTML-отчёт формируется локальным запуском `run_tests.bat` и сохраняется как `index.html` в этом каталоге.

После локального запуска можно сохранить скриншот итоговой таблицы покрытия в `doc/screenshots/coverage_report.png` и внести фактические проценты в `doc/readme.md`.

Сгенерированный HTML может быть локальным артефактом и не включаться в репозиторий, если преподаватель не требует его загрузки.
