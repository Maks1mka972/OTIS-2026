## Анализ устойчивости

Для модели 1.5:

`y[n+1] = a_1 y[n] + a_2 y[n-k]`

характеристическое уравнение:

`z^{k+1} - a_1 z^k - a_2 = 0`

Система считается асимптотически устойчивой, если все корни характеристического уравнения строго внутри единичного круга:

`|z_i| < 1`

Граничный случай `|z| = 1` не считается асимптотически устойчивым.
